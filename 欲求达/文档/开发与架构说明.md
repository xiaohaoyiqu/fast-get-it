# 开发与架构说明

程序通过桌面界面、平台适配器、爬虫和公共服务组织功能。平台代码遵循统一任务与事件协议，界面通过队列接收后台结果。

## 运行入口

`run_software.py` 提供桌面启动和命令行命令，`software_app/app.py` 创建存储、任务管理器及平台适配器。

| 位置 | 职责 |
| --- | --- |
| `software_app/adapters/` | 平台目标、预览及下载的统一入口 |
| `software_app/crawlers/` | 平台请求、解析与媒体发现 |
| `software_app/core/` | 任务、SQLite、传输、文件、浏览器和账号服务 |
| `software_app/ui/` | Tk 桌面界面及对话框 |
| `tests/` | 自动回归与手动验收源码 |
| `scripts/` | 静态质量和文档检查 |
| `pyinstaller_hooks/` | 冻结版资源收集与启动兼容 |

## 任务与事件

`TaskManager` 注册适配器并管理任务线程，任务使用结构化选项、状态和文件记录。进度、文件和完成事件通过回调发送到界面队列，由 Tk 主线程更新控件。

任务支持排队、运行、暂停、取消、完成、部分完成和失败。暂停在下载分块或循环等安全检查点生效，保留并发槽位及输出锁。取消会通知平台和受管理的外部进程。

任务默认保存创建时的配置。按原设置重试保留快照；选择按当前设置重试才重新读取设置。人物配置仅匹配明确的账号目标，不保存 Cookie。

实例租约和操作系统锁保护共享数据库中的任务归属。恢复中断任务需要用户操作，不在启动时自动发起网络请求。跨实例远程暂停或取消尚未接入。

## HTTP 与 HLS 传输

公共 HTTP 传输复核入口、最终资源地址、服务器验证器及总长度。续传状态记录本地有效前缀和 SHA-256；恢复前检查前缀，舍弃未提交尾部，状态不可信时重新下载。

Bluesky 的点播 HLS 可复用经过验证的完整分片与初始化数据，不恢复半个分片。资源范围或身份变化时重新获取，不将直播播放列表视为可恢复的固定点播任务。

主机退避采用单调时钟，支持暂停和取消，有效 Retry-After 保留完整期限。HTTP 媒体共用实例内带宽预算；浏览器、外部引擎及其他实例不共享该预算。aria2 的下载／上传限制按进程分别设置。

## 文件与媒体处理

主要下载及转换路径使用线程和进程间输出锁，按复用、覆盖、报错或自动改名策略处理重名。写入索引时记录实际成品路径。

成品先写入临时位置，验证完成后提交。共享媒体进程入口支持取消、超时和有界诊断；转换失败不发布临时成品。归档清理源文件前核对身份与摘要，不满足条件时保留源文件。

下载库清理先生成计划，再检查文件与索引是否变化。手动成品清单使用相对路径、大小和 SHA-256，核验可报告变化、缺失、占用等状态；它证明相对本地基线的变化，不证明来源可信。

## 平台集合与补下

Pixiv 收藏、漫画系列、作品搜索和排行榜保存固定作品范围，部分集合进一步记录逐媒体结果。仅补未完成媒体沿用原范围和输出目录；完整重试才重新发现集合。发现中断不能当作已完整扫描。

平台适配器需要保留任务取消、日志脱敏、URL 校验、输出锁和文件登记约定。新增平台接口见 [插件开发](插件开发.md)。

## 浏览器与登录资料

受管理的 Windows Selenium 会话使用独立 Job Object 管理驱动及其子进程，不按进程名清理用户浏览器。会话数量和可选内存准入独立于下载并发设置。

Cookie 按目标域筛选，跳转时复核凭据策略，禁止向无关站点发送敏感标头。E-Hentai 与 ExHentai 使用独立资料；保存不联网，验证单独执行。

## 界面布局

`tk_app.py` 组织工作台，平台候选、相似搜索、任务、下载库和设置分为独立模块。

`layout.py` 提供按钮自动换行、提示文字换行和受限高度的滚动操作区。常用操作放在主工具栏，批量任务、人物配置等放在“更多操作”。设置保存区固定在滚动内容之外。

任务操作区与日志区、搜索操作区与结果表分别保留空间。调整窗口时重新计算按钮列数和分栏高度；隐藏平台按钮不参与排版。资料卡的尺寸与滚动范围事件使用追加绑定，避免互相覆盖。

手动布局验收覆盖不同窗口尺寸和字体缩放，检查控件可达性、同级遮挡、日志高度及结果表高度。见 [测试说明](../tests/README.md)。

## 数据与安全

SQLite、Cookie、浏览器资料、任务历史和下载文件保存在运行数据或用户指定目录。`YUQIUDA_HOME` 和 `YUQIUDA_OUTPUT_DIR` 应在导入设置模块前配置；已保存的下载目录优先于默认值。

公开文档和错误信息不应包含真实凭据。任意网页链接必须经过外部 URL 检查，重定向仍需复核；安全检查不能由平台适配器随意绕过。

## 检查与打包

```powershell
python -m unittest discover -s tests
python scripts/check_quality.py
python scripts/check_documentation.py
python -m PyInstaller 欲求达.spec --clean --noconfirm
```

打包需要图标及匹配的 ChromeDriver。GUI 和 CLI 为独立单文件程序，运行数据保留在程序运行根目录。源码回归、原生操作、平台实站和打包启动分别验证，不互相替代。
