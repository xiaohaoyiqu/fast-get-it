# 更新日志

按源码修改日期汇总，同一天的改动合并记录。可执行文件的更新以发行记录为准，使用范围见[用户手册](用户手册.md)。

## 2026-11-01

### 功能增减

- 新增 HentaiPaw 作品链接和数字 ID 识别、在线预览、关键词搜索及阅读器原图下载。
- 新增 HentaiPaw 独立 Cookie 导入，支持 JSON、cookies.txt 和 Cookie 请求头；遇到登录或验证要求时提示处理。
- HentaiPaw 接入混合链接队列和作品黑名单，下载结果写入下载库，支持取消、重试和图片格式转换。
- HentaiPaw 新增逐页下载结果和仅补未完成页，支持取消后继续补下。
- HentaiPaw 新增标签、原作、角色、作者和团队分类，以及日、周、月和总榜。
- 新增 HentaiPaw 软件收藏管理，支持导入浏览器本地收藏、合并、导出备份，并从收藏选择作品下载。
- HentaiPaw 设置页新增站点访问与会话配置检查，区分页面可访问和账号身份已验证。

### 功能变化

- E-Hentai / ExHentai、Google 相似图片和网页资源从“试验”调整为“可用”。
- 命令行搜索和下载使用软件已保存的代理设置。
- HentaiPaw 接受阅读器链接，搜索可以继续翻页并去重；补下沿用原目录，磁盘错误会停止后续下载。
- 主动报告文件的适配器失败后不再扫描整个保存目录，避免将其他作品误记为当前任务的结果。

### 体验

- HentaiPaw 将 Cookie 导入标明为可选；补充找不到 Cookie 时直接使用，以及从 Local Storage 导入 favorites 收藏的步骤。
- 各平台错误提示区分网络、代理、证书、本地文件、站点验证和明确的登录要求，Cookie 格式错误保留具体原因。
- Pixiv、FANBOX、JMComic、EH 和 HentaiPaw 的设置检查显示网络方式；配置未保存时提醒后续下载仍使用旧值，联网检查记录耗时。
- 补齐设置检查、Cookie 导入结果、EH 收藏、Bluesky 关注和 HentaiPaw 软件收藏的本地操作日志；切换 Cookie 平台后，旧结果不再覆盖当前提示。
- Bluesky、Instagram 和 HentaiPaw 下载补充读取内容阶段的进度提示。
- 欲求达的源码、测试、文档和打包配置统一放进 `欲求达/`，原启动命令继续可用，现有账号与下载记录沿用原位置。
- 更新日志改为按日期汇总，区分体验、功能变化和功能增减。
- HentaiPaw 在线资料显示封面和核实后的页数，下载不再受其他平台残留的视频筛选影响。
- 后台刷新 Twitter 关注或历史时，不再覆盖正在查看的其他平台资料卡。
- 修复从“规划中”切回可用下载范围后，开始按钮仍被禁用的问题。
- 搜索固定使用发起时的设置，较早返回的搜索结果和错误不再覆盖新搜索或其他平台页面。
- EH 和 HentaiPaw 候选页可执行对应搜索；搜索进行时保持刷新按钮状态，结束后恢复操作。
- 批量预览保留 HentaiPaw 的页数和阅读器验证状态。
- 分类目录可展开并翻页浏览；目录本身禁止直接下载，选中具体作品后再加入队列。

## 2026-10-31

- 修复浏览器关闭、崩溃后的任务状态和进程回收；工具安装失败时保留原有可用版本。
- 修复媒体转换取消和长时间限流等待，取消任务时回收本次转换进程。

### 体验

- 调整主界面、任务队列和设置页的滚动与按钮布局，小窗口下可以访问完整操作区，保存设置按钮保持可见。
- 精简 README 和使用文档，补齐源码启动、依赖安装与本地打包说明。
