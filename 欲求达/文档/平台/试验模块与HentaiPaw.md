## HentaiPaw 登录核查

通过系统代理匿名读取首页、作品详情和阅读器，均返回 HTTP 200；`/login` 返回 HTTP 404。公开页面及已读取的公开脚本未发现可确认的账号登录接口或必要会话 Cookie 名称。用户在网页下载操作中看到的登录提示，是否属于前端限制仍未确认，不能据此认定全站不需要登录。

使用实际客户端匿名下载一页，得到有效 WebP 图片（1360 × 2040，231002 字节）。该样本阅读器包含 202 页原图，关键词搜索也返回候选。本次没有使用真实账号 Cookie，也没有验证账号限定内容。

已确认的页面结构：

- 中文首页：`https://zh.hentaipaw.com/`。
- 详情页：`/articles/数字ID`。
- 搜索表单：`/articles/search`，关键词参数 `keyword`。
- 阅读器：`/viewer?articleId=数字ID&page=页码`。
- 详情页图片路径包含 `/thumbnails/`，封面及分页缩略图不等于阅读原图。

## Cookie 导入

**浏览和下载公开作品不需要导入任何文件。** 浏览器的 Cookies 列表为空，或没有本站条目时，可以先在设置中点击“检查站点访问（联网）”，再直接搜索、预览和下载。这个可选入口不表示必须取得 Cookie 才能使用，也不要创建空文件或填入其他平台的 Cookie。

如果你想导入的是网站收藏，需要的是 **Local Storage 中 `favorites` 的 JSON 值**，不是 Cookie。请使用下方的“导入浏览器收藏”流程；两种文件使用不同入口。

设置 → 浏览器登录与 Cookie → HentaiPaw → 导入 Cookie 文件。支持 JSON、Netscape `cookies.txt` 和 `Cookie:` 请求头文本，单独保存在 `data/software_app/hentaipaw/cookies.json`。保留 Cookie 的域、路径、HTTPS 和过期时间；拒绝其他平台域的 Cookie。请求头 TXT 也可先转换成 JSON 再导入。

当前使用导入方式，不提供未经核实的自动账号登录流程。导入成功只表示配置已保存，不显示“账号登录已验证”；公开页读取成功也不能证明账号已登录。未配置 Cookie 时尝试公开访问；遇到 HTTP 401/403 或阅读器跳转时，会提示检查登录、站点验证及代理。原图 CDN 使用匿名会话，不接收站点 Cookie。

设置页新增“检查站点访问（联网）”，使用当前填写的代理和已保存 Cookie 检查公共页面。结果分别表示 Cookie 是否配置、页面是否可访问；账号身份始终保留“未验证”，不会用公共页面的 HTTP 200 代替账号验证。当前公开页面及作品脚本仍未发现可确认的账号登录接口。

## 分类与排行榜

范围列表新增标签、原作、角色、作者和团队分类，以及日榜、周榜、月榜和总榜。

- 分类范围留空搜索会读取索引；输入名称可筛选当前索引页，使用“上一页分类／下一页分类”浏览其他索引页。
- 选择分类后点击“展开分类”，读取该分类下的作品；也可直接输入本站分类链接或数字分类 ID。
- 分类目录只供浏览，不能直接加入下载队列。展开后选择具体作品，使用原有预览和下载流程。
- 排行榜留空执行搜索即可读取。列表最多显示 100 项，按需要继续读取作品列表分页；分类索引按页浏览，不承诺一次搜索覆盖全站分类名称。

日榜、周榜、标签目录、作者目录和标签作品列表已做匿名实站只读验证。

## 浏览器收藏与软件收藏

本站收藏页和作品脚本使用 `localStorage.getItem("favorites")` 保存收藏，收藏数据属于当前浏览器，不在 Cookie 文件中，也没有确认可读取的服务器账号收藏接口。

软件提供独立收藏文件 `data/software_app/hentaipaw/favorites.json`。候选页可加入或移出软件收藏，选择“软件收藏”范围可读取并下载收藏作品。

1. 在原来收藏作品的同一浏览器打开当时使用的站点域名，进入 F12 → Application → Local Storage → 本站，复制 `favorites` 的完整值，以 UTF-8 保存为 `hentaipaw-favorites.json`。
2. 在软件候选页点击“导入浏览器收藏”。导入会合并已有软件收藏，只保留作品 ID、标题及必要展示字段。
3. 点击“导出软件收藏”保存为浏览器兼容的 JSON，可用于备份或手动合并回浏览器的 `favorites` 值。

导入导出不会自动改写浏览器收藏；回写浏览器前应保留其原值。软件最多保存 10000 项、文件上限 8 MiB，列表按请求数量展示，可以按标题或 ID 筛选。导入失败保留已有收藏，更新使用文件锁和原子写入。

如果 Local Storage 中没有 `favorites`，先在原网站收藏一部作品，再刷新开发者工具中的存储列表；不同浏览器和域名的本地收藏不共享。也可以直接在软件候选页加入“软件收藏”，无需从浏览器导入。

## 预览、搜索与下载

`hentaipaw` 模块标记为可用，支持数字 ID、HTTPS 详情和阅读器链接、本地识别、在线作品预览、关键词搜索和阅读器原图下载。阅读器链接会转成作品目标，从第一张开始下载。搜索可按请求数量继续翻页、去重，最多返回 100 项，桌面默认显示 20 项候选。混合链接批次自动识别 HentaiPaw，数字 ID、详情链接与阅读器链接共享作品黑名单标识。

桌面使用步骤：

1. 选择 HentaiPaw，输入作品 ID、详情链接或阅读器链接；也可在左侧按关键词搜索，再选择候选加入下载队列。
2. “本地预览”只识别目标；“在线获取资料”会核实阅读器、显示总页数和封面。封面读取使用已保存的代理设置。
3. 确认保存目录和图片格式后开始下载。漫画按图片处理，不会沿用其他平台残留的“仅视频”筛选。
4. 在任务详情查看逐页结果；部分失败显示“部分完成”，可以仅补未完成页或选择失败页补下。取消后剩余页保留为待处理。

原图列表来自阅读器的 Next.js 数据，按 JSON 和字节长度解析，不执行页面脚本。校验作品 ID、CDN 域名、原图路径及连续页码，拒绝以缩略图代替原图。下载复用公共传输引擎，支持重试、可验证的断点续传、复用已有文件、取消、图片校验及输出格式转换，同时保存作品元数据并把结果写入下载库。

下载前登记逐页计划，记录已保存、已复用、失败与待处理。补下刷新原图地址并核对作品和媒体身份，沿用原日期目录，不把已成功页重新列入补下范围。部分完成任务不自动归档；磁盘空间、权限等本地错误停止后续下载。已经主动报告文件的适配器在失败后不会再广泛扫描下载根目录，避免把其他作品登记进当前任务。

逐页清单适用于接入此功能后执行的任务。旧任务若没有逐页记录，需要整项重试，不能凭文件名自动补造清单。

请求复用网页模块的公开目标检查、重定向检查、超时、取消和 5 MB HTML 上限。在线预览返回的可见页链接数不承诺等于总页数；核实后的总页数和下载列表取自阅读器。

本轮实站复查在隔离数据库下下载三页，每页均为可校验的 1360 × 2040 图片。第一张保存后取消，任务保留一张成功与两张待处理；补下仅处理后两张，再次执行时三张均复用。跨页搜索返回 40 个不重复候选，空结果查询返回 0 项。本轮仍未使用账号 Cookie。

收藏已按站点实际的浏览器本地存储方式接入导入导出和软件内管理。Cookie 导入可用于站点会话，但公开作品验收结果不代表账号限定内容也已通过。
