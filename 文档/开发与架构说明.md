# 欲求达开发与架构说明

欲求达采用桌面界面、平台适配层、爬虫实现和公共服务分层。平台代码通过统一任务模型接入，界面不直接依赖具体网站的请求细节。

## 目录结构

```text
run_software.py
software_app/
  app.py
  adapters/
  core/
  crawlers/
  ui/
文档/
```

- `run_software.py` 提供桌面入口和诊断命令。
- `software_app/adapters/` 负责平台注册、目标规范化、候选预览和任务参数转换。
- `software_app/crawlers/` 保存各平台的页面、接口和媒体下载实现。
- `software_app/core/` 提供任务、事件、SQLite、浏览器驱动、登录资料、压缩、黑名单和安全规则。
- `software_app/ui/` 包含 Tkinter 页面、主题、预览、任务队列和下载库。

## 适配层

每个平台实现 `CrawlerAdapter`，并通过插件加载器注册。适配器承担以下工作。

- 判断输入是否属于当前平台；
- 把用户名、作品 ID、章节 ID或网址转换为规范目标；
- 返回结构化预览；
- 创建统一的 `DownloadTask`；
- 调用平台爬虫并返回文件记录。

界面只使用适配器提供的名称、能力和回调，不直接导入网站客户端。

## 任务与事件

`TaskManager` 管理排队、运行、取消、重试和完成状态。平台通过 `CallbackSet` 上报日志、进度与文件，公共存储层把任务、历史和文件索引写入 SQLite。

批次监视由任务队列界面维护目标顺序：优先显示正在运行的批次成员，否则显示下一项排队任务。手动选择其他任务会暂停该批次的自动聚焦。Twitter 爬虫为每个媒体结果发送进度事件，并在文件成功或复用时发送 `FileRecord`，因此任务详情可实时列出单文件结果和原因。详情筛选和导出使用任务最近 500 条日志。

平台可以声明并发上限。达到上限后的任务保持排队，当前任务结束后自动取得空闲槽位。取消操作会向爬虫传播 `TaskCancelled`，浏览器、网络请求和后处理都应尽快结束并清理临时文件。

## 下载与文件处理

公共下载能力集中在 `software_app/crawlers/common.py` 和 `software_app/core/`，包括以下内容。

- 统一请求超时、代理、重试和原子写入；
- 文件名清理与输出目录规范化；
- 图片格式转换、漫画长图和 PDF；
- ZIP 压缩、解压和路径穿越防护；
- aria2 BT 任务、取消和停止做种；
- 下载文件登记与历史索引。

平台爬虫只负责生成可信媒体地址和元数据，不应绕过公共安全规则自行写入任意路径。

## 登录与浏览器

Twitter/X、Pixiv、FANBOX 和 Instagram 可以使用临时可见浏览器完成登录。JMComic、E-Hentai 和 ExHentai 使用普通 Chrome 资料，关闭专用窗口后再读取 Cookie 数据库。

E-Hentai 表站和 ExHentai 里站使用独立资料与 Cookie 文件，允许配置不同账号。请求头 TXT 导入只保留允许的 Cookie 和 User-Agent，并在覆盖现有会话前检查必需字段。

ChromeDriver 由 `core/browser_driver.py` 统一管理。程序读取 Chrome 主版本，选择对应驱动并在替换前验证可执行文件版本。

## 数据与安全边界

运行数据位于 `data/software_app/`，包括 SQLite、Cookie、浏览器资料、任务记录和缓存。该目录不会进入源码仓库。

所有外部 URL 都要经过协议、主机和凭据检查。通用网页下载拒绝回环、内网及保留地址；平台客户端把 Cookie 限定在对应站点域名，不向图片 CDN、种子站或无关主机发送账号会话。

日志、任务参数和界面详情会隐藏 Cookie、token、密码、密钥及含凭据的网址。插件以当前用户权限运行，只应启用已经阅读并信任的代码。

## 界面模块

`tk_app.py` 负责主窗口和跨页面协调，各功能页分工如下。

- `following_tab.py` 管理平台候选、关注、收藏与历史；
- `google_search_tab.py` 提供相似图片搜索；
- `task_queue_tab.py` 管理队列、日志与任务操作；
- `library_tab.py` 提供下载文件浏览、搜索和管理；
- `settings_tab.py` 管理平台配置、登录资料和公共选项；
- `preview_renderer.py` 负责安全的结构化资料与 HTML 静态预览。

页面之间通过主窗口状态和公共事件协作，平台逻辑仍留在适配器与爬虫层。

## Windows 打包与启动兼容

PyInstaller 通过 `pyinstaller_hooks/rthook_force_stdlib_json.py` 固定 Requests 使用 Python 标准库 JSON。Requests 会把可导入的 `simplejson` 当作完整可用的可选依赖；便携版若覆盖更新留下不完整的旧 `simplejson` 目录，程序会在启动导入阶段因缺少 `JSONDecodeError` 退出。更新时应关闭程序并整体替换 `_internal`，同时保留 exe 同级的 `data/` 用户数据目录。
