# 仓库与目录说明

欲求达桌面端与浏览器用户脚本分成两个仓库维护。

| 内容 | GitHub 仓库 |
| --- | --- |
| 欲求达源码和文档 | [xiaohaoyiqu/fast-get-it](https://github.com/xiaohaoyiqu/fast-get-it) |
| Tampermonkey 用户脚本 | [xiaohaoyiqu/tempermonkey-scripts](https://github.com/xiaohaoyiqu/tempermonkey-scripts) |

## 为什么分开

油猴脚本可以直接从 GitHub Raw 地址安装，有自己的版本号和更新记录。桌面端使用 Python、Tkinter、SQLite 和外部工具。两边共享平台解析经验，但运行时不互相依赖。

项目没有使用 Git submodule。需要两部分内容时分别克隆：

```powershell
git clone https://github.com/xiaohaoyiqu/fast-get-it.git
git clone https://github.com/xiaohaoyiqu/tempermonkey-scripts.git
```

## 源码目录

`software_app/` 保存桌面端、平台适配器、爬虫实现和公共服务，`run_software.py` 是统一入口。运行和打包依赖列在 `requirements-app.txt` 中；`requirements-dev.txt` 在其基础上增加 Ruff 和验收所需的 psutil，检查规则位于 `ruff.toml`。PyInstaller 打包配置为根目录的 `欲求达.spec`。

修改平台功能时，应从 `software_app/adapters/` 和 `software_app/crawlers/` 找到对应模块；跨平台任务、存储和浏览器能力位于 `software_app/core/`。

| 路径 | 维护用途 |
| --- | --- |
| `tests/` | `unittest` 测试与 `manual/` 验收源码，执行入口和边界见 [测试说明](../tests/README.md) |
| `scripts/` | 静态质量检查与文档链接／JSON 示例检查；不启动桌面或访问账号 |
| `文档/` | 使用、平台、开发、设计与固定入口测试报告；QQ Bot 接入建议保留为 TXT |
| `requirements-dev.txt` / `ruff.toml` | 开发依赖、Python 3.10 语法目标与基础静态检查规则 |
| `pyinstaller_hooks/` | 打包资源收集和冻结版启动兼容 |
| `欲求达.spec` | GUI / CLI 单文件 exe 构建配置 |
| `software_app/crawlers/twitter/` | 当前桌面端实际调用的 Twitter 实现 |

本地还可能存在 `推特爬虫/`、`Pixiv爬虫/`、`JMComic爬虫/`、`谷歌图片搜索工具/` 和独立的 `greater-trawler/` 参考仓库。这些参考实现不等于当前主仓库的维护入口；排查修改范围时以 `git ls-files`、`git status --short` 和 `run_software.py` 的导入关系为准。不要把所有同名副本一起修改。

## 运行位置与打包输入

默认源码运行根为项目目录，exe 运行根为 exe 所在目录；`YUQIUDA_HOME` 可覆盖运行根，数据放在其下的 `data/software_app/`。默认下载目录为源码根下 `data/downloads/` 或当前用户的 `Downloads/欲求达/`，也可由 `YUQIUDA_OUTPUT_DIR` 和界面设置调整。

界面优先恢复保存在 SQLite 设置中的上次目录，未配置时才回退默认目录；更改环境变量不会自动覆盖已保存的选择。Twitter 成功/失败、账号下载历史和隐藏历史 JSON 通过规范化路径对应的操作系统文件锁协调当前版本进程，写入在锁内强制重读并原子替换；缓存仍仅在进程内共享。旧版或外部程序不遵守该锁时不受保护。

`欲求达.spec` 需要根目录 `1.ico` 和 `software_app/crawlers/twitter/chromedriver.exe`。后者不进入 Git，打包机需自行准备。构建结果 `dist/欲求达.exe`、`dist/欲求达-cli.exe` 均为单文件；运行时的临时解压目录与持久用户数据目录用途不同，更新 exe 时保留运行数据和下载目录。

## 不进入仓库的内容

`data/software_app/` 中可能包含 Cookie、请求头、SQLite、浏览器资料、任务历史、缩略图和下载文件，因此整体排除。虚拟环境、缓存、日志、ChromeDriver 和下载记录也不会进入仓库。

本地检查日志、临时性能测量和检查工具放在被忽略的运行目录中；不要为了提交检查结果而把整个 `data/` 或运行数据库加入 Git。仓库保留可复现的测试源码和检查配置，测量摘要见更新日志。

## 远程地址

主仓库的 `origin` 使用 `https://github.com/xiaohaoyiqu/fast-get-it.git`，油猴脚本仓库使用 `https://github.com/xiaohaoyiqu/tempermonkey-scripts.git`。

```powershell
git remote -v
git -C .\油猴脚本 remote -v
```

推送前应确认待提交文件中没有账号资料、Cookie 或下载内容。
