# 仓库与目录说明

欲求达桌面端、浏览器用户脚本和旧参考源码分成三个仓库维护。

| 内容 | GitHub 仓库 | 本地目录 |
| --- | --- | --- |
| Windows 桌面端 | [xiaohaoyiqu/fast-get-it](https://github.com/xiaohaoyiqu/fast-get-it) | 当前项目根目录 |
| Tampermonkey 用户脚本 | [xiaohaoyiqu/tempermonkey-scripts](https://github.com/xiaohaoyiqu/tempermonkey-scripts) | `油猴脚本/` |
| 旧参考爬虫归档 | [xiaohaoyiqu/greater-trawler](https://github.com/xiaohaoyiqu/greater-trawler) | `greater-trawler/` 或单独克隆目录 |

## 为什么分开

油猴脚本可以直接从 GitHub Raw 地址安装，有自己的版本号、更新记录和发布节奏。桌面端使用 Python、Tkinter、SQLite 和外部工具，发布方式是 Windows 程序目录或安装包。两边会参考相同的平台解析经验，但运行时不互相依赖。

`油猴脚本/` 保留独立的 `.git` 和 `origin`。主仓库的 `.gitignore` 排除了这个目录，防止它被误当成普通文件夹提交。这里没有使用 Git submodule；分别克隆两个仓库更容易安装脚本，也不会要求桌面端用户额外初始化子模块。

```powershell
git clone https://github.com/xiaohaoyiqu/fast-get-it.git
git clone https://github.com/xiaohaoyiqu/tempermonkey-scripts.git
git clone https://github.com/xiaohaoyiqu/greater-trawler.git
```

## 当前源码和旧目录

`software_app/` 是桌面端当前实现。`run_software.py` 是统一入口，`tests/` 保存离线回归测试，`scripts/` 与 `packaging/` 负责烟测和 Windows 构建。

下面这些目录只留作旧行为参考，不作为当前程序入口。主仓库的 `.gitignore` 会排除它们；其中可公开的参考源码另行整理到 `greater-trawler`，Cookie、下载内容和本机数据不会进入归档。

- `推特爬虫/`
- `Pixiv爬虫/`
- `JMComic爬虫/`
- `谷歌图片搜索工具/`
- `app_core/`、`adapters/`、`desktop_ui/`
- `prototype.py`、`run_desktop.py`

修改新功能时，应在 `software_app/` 中找到对应平台或公共服务。只有核对旧行为时才读取旧目录。

旧实现所参考的上游项目和许可证见 [鸣谢](鸣谢.md)。`谷歌图片搜索工具/` 是项目作者自己的早期实现，不属于第三方参考源码。

## 哪些内容不能提交

`data/software_app/` 全部属于运行数据，其中可能有 Cookie、请求头、SQLite、浏览器资料、任务历史、缩略图和下载文件。该目录已经整体加入 `.gitignore`。

`.venv/`、`build/`、`dist/`、Python 缓存、ChromeDriver 和旧源码目录同样不会进入主仓库。正式发行文件应通过 GitHub Releases 或其他发布渠道提供，不应把整个 `dist/` 直接提交到源码分支。

根目录的 aria2 ZIP 是构建输入。构建脚本会检查固定 SHA-256，再把它放入发行目录；程序首次安装 aria2 时只提取允许的可执行文件和许可文档。

## 远程和发布操作

主仓库本地 `origin` 指向 `https://github.com/xiaohaoyiqu/fast-get-it.git`。油猴脚本仓库的 `origin` 指向 `https://github.com/xiaohaoyiqu/tempermonkey-scripts.git`。旧参考源码归档使用 `https://github.com/xiaohaoyiqu/greater-trawler.git`。

可以用下面的命令复核。

```powershell
git remote -v
git -C .\油猴脚本 remote -v
```

配置远程不会自动上传内容。提交和推送仍应在检查待提交文件、确认没有账号资料后单独执行。
