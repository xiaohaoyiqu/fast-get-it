## 一手资料与实际决定

- [yt-dlp HTTP](https://raw.githubusercontent.com/yt-dlp/yt-dlp/master/yt_dlp/downloader/http.py)、[fragment](https://raw.githubusercontent.com/yt-dlp/yt-dlp/master/yt_dlp/downloader/fragment.py)：核对范围响应、恢复状态不一致和分片策略。不直接采用所读 HTTP 源码的 416 近似长度成功判定，也不把可配置跳片等同于本项目完整媒体成功。
- [gallery-dl archive](https://gdl-org.github.io/docs/configuration.html#extractor-archive-mode)：区分完成身份、写入事件和整次成功后写入。作品范围快照与媒体成功记录在本项目仍是两份协议。
- [aria2 手册](https://aria2.github.io/manual/en/html/aria2c.html)：核对每进程限速、no-conf 和可信 checksum 的作用范围。本机摘要只支持变化检测，不证明来源真实；尚无跨进程统一预算。
- [Ghost ADR 0015 固定版本](https://github.com/XiaoYouChR/Ghost-Downloader-3/blob/ee0cb1aa5325960e6a2584b4c3029982e288c7a3/docs/adr/0015-part-path-beside-each-output.md)：未完成状态可与预分配成品共存，不照搬其提交／删除假设。
- [RFC 9110 §8.8.1](https://www.rfc-editor.org/rfc/rfc9110.html#section-8.8.1)：不同资源可能使用相同验证器，因此公共 HTTP 与 HLS 复用都核对最终资源身份。
- [RFC 8216](https://www.rfc-editor.org/rfc/rfc8216.html)：用于界定有限 HLS 布局。本机实测 FFmpeg 能跳过坏 TS 仍零退出，有限容器检查独立于引擎退出码，不宣称逐帧完整。
- [Windows Job Objects](https://learn.microsoft.com/en-us/windows/win32/procthread/job-objects)、[进程分配](https://learn.microsoft.com/en-us/windows/win32/api/jobapi2/nf-jobapi2-assignprocesstojobobject)：本次创建驱动的句柄建立归属，正常退出后回收本组，应用强杀由关闭句柄兜底；不会据路径字符串认领用户浏览器。
- [Motrix 官方 README](https://raw.githubusercontent.com/agalwood/Motrix/master/README.md)：撤回此前 SQLite 会话／插件隔离权限的无依据归因。保留有来源支持的协议、并发、限速与任务删除交互。

在线 master／main 与文档按读取日记录，不作为固定提交或发布版本保证。部分 GitHub raw 抓取受限后改读 raw.githubusercontent.com；FFmpeg 官网抓取失败的轮次采用本机生成样本实测，不冒充官方文档结论。

## 当前已落实与边界

本地成品清单与只读核验参考 rclone check 的只读差异分类、gallery-dl／yt-dlp 的必要元数据旁文件思路，在本项目独立实现。未引入这些引擎，不导出其完整内部信息。版本化清单只建立当前文件的本地摘要；RFC 9530 来源摘要语义、下载时自动基线和转换产物关系尚未接入。

搜索／排行扩展后的复查补读 Ghost 同一快照的 ADR 0012／0017／0020，以及 rclone check、FFprobe、SQLite FTS5 和 RFC 9530。新增公共链路审查与验收候选见 [开源下载器对比](开源下载器对比.md)。初次评估只核对了长 Retry-After 纯函数返回值；随后已接入通用转换取消、移除长退避截短并补回归，见最新测试报告。手动本地成品清单和只读核验已实现；可信来源校验及自动产物关联仍为候选。大库成本仍为源码审查，没有性能测量。

已落实收藏作品范围计划、作品收藏逐页／动图组补下、其他 Pixiv 集合发现检查、Bluesky 有限 HLS 恢复、受控缓存清理、aria2 独立预算、工具候选验证、浏览器会话错误传递和 Windows 进程所有权。

公共 HTTP 版本 3 增加本地摘要检查点，恢复前校验前缀并丢弃未提交尾部，不能再把“HTTP 尚无本地变化检测”当作当前状态。旧版本 1／2 内部缓存保守重取；摘要不替代可信来源 checksum，也不对恶意同时改写记录提供证明。

漫画系列、作品搜索和排行榜现已接入持久范围及精确补下，复用现有集合计划、媒体身份和事务，不复制第三方实现。补充查阅 [gallery-dl Pixiv](https://raw.githubusercontent.com/mikf/gallery-dl/master/gallery_dl/extractor/pixiv.py) 的系列／作品／页身份组织及 [archive 源码](https://raw.githubusercontent.com/mikf/gallery-dl/master/gallery_dl/archive.py) 的完成记录；其 App API 与本项目网页接口不同，不据此证明接口兼容。参考 master 是读取时资料，不作为固定版本保证。

后续评估新作／作者标签等其他 Pixiv 集合持久范围与精确补下、可信来源与成品清单、跨进程引擎预算及时间窗口。平台实站业务、真实 P2P 上传吞吐和长期压力没有被这些离线验收替代；不自动请求此前跳过的 Pixiv 账号。
