# 更新日志

本文件记录「欲求达」各版本的功能变更、问题修复和使用说明调整。

## 2026-09-24

### 问题修复

- **保存路径切换卡死**：修复切换到非 C/D 盘（网络驱动器、移动硬盘等）时界面卡死的问题。原因是下载历史加载在 UI 主线程同步递归遍历目录，现已改为后台线程异步执行。
- **在线获取资料卡死**：修复点击「在线获取资料」和「本地预览」时界面卡死的问题。`load_profile_preview` 同样在主线程同步遍历输出目录，现已全部改为后台线程。
- **打包后在线获取失败**：修复打包版提示「推特脚本目录不存在」「缺少 config.json」的问题。PyInstaller 配置已包含 twitter / pixiv / jmcomic 爬虫脚本目录。
- **目录遍历异常保护**：`downloaded_users` 中的目录遍历增加 `try/except`，单个子目录或文件不可访问时自动跳过，不再导致整体加载失败。

### 新增功能

- **任务开始前确认弹窗**：点击「开始任务」后弹出确认窗口，展示当前下载设置，包括统一输出格式、公共压缩/解压、当前平台设置、保存目录和代理，并提示资源占用。点击「是」继续，「否」取消。
- **下载完成弹窗**：任务正常完成后弹窗显示任务 ID、下载文件数、总大小和保存目录；任务失败时弹窗提示查看日志。

### 配置与打包

- **数据存储位置调整**：打包版（exe）的运行数据（数据库、Cookie、浏览器配置、ChromeDriver 等）从 `%LOCALAPPDATA%/YuqiuDa/` 改为 **exe 所在目录的 `data/` 文件夹**，实现绿色便携。源码运行版仍使用项目目录下的 `data/`。
- **ChromeDriver 位置**：统一保存在 `data/software_app/browser/chromedriver.exe`，设置页可自动检测和安装。
- **打包配置**：新增 `欲求达.spec`，包含爬虫脚本数据打包，生成 GUI 版（欲求达.exe）和 CLI 版（欲求达-cli.exe）。

### 压缩功能说明

- 默认压缩模式为「不压缩」，需在设置页手动开启。
- 「按资源文件夹压缩」：每个子文件夹生成一个 ZIP，保存在该文件夹内，命名为 `{文件夹名}_归档_{任务ID}.zip`。
- 「按整个任务压缩」：在任务输出根目录生成一个 ZIP。
- 开启「压缩校验成功后清理源文件」后，仅在 ZIP 写入并校验通过后删除源文件。
