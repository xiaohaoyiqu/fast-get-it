# 更新日志

本文件记录「欲求达」各版本的功能变更、问题修复和使用说明调整。

## 2026-09-25

### Twitter/X 页面恢复

- 媒体页等待阶段若检测到 X 明确显示临时错误并要求重新加载，自动刷新一次后重新等待媒体列表。
- 登录或账号限制页面不会触发自动刷新；仅在媒体列表为空且错误提示包含重载/重试指引时生效，刷新动作会写入任务日志。

### 文档补充

- 增加打包版 `VCRUNTIME140.dll` / `VCRUNTIME140_1.dll` 的占用原因、进程排查及安全更新说明。

### 任务队列修复

- 双击任务记录改为显式使用鼠标所在行，避免多选/旧选中状态让工作台总填入第一条任务。
- 同步修复候选、平台历史、相似图片和下载库双击操作的行选择；Twitter 历史读取正确的数据列表；相似图片预览按钮限制为单项。
- 任务失败或取消时扫描并登记本次已写入磁盘的文件，错误详情说明保留数量，避免部分下载文件无任务索引。
- 批量重试创建新任务前先显示平台、目标和任务数量确认；取消确认不会创建任务。
- 任务队列允许选择同一平台的多项任务并用 `/` 填入工作台；跨平台选择会提示先按平台筛选。预填目标保留为准确列表，搜索词或文件路径含 `/` 时也不会被误切分。
- 多选填入时仅在所选任务的下载类型/目标类别一致时恢复对应设置；输出目录保留工作台当前值，避免把首条任务的目录套用给整批目标。
- 检查了各平台下载适配器到任务管理器的共同处理路径：文件索引、失败部分文件扫描，以及成功后的公共压缩/解压后处理仍由 TaskManager 统一负责。

### 多目标获取与安全优化

- 增加“批量获取资料”：依次获取多个作者/作品资料，在左侧结果列表逐项查看；左侧资料卡一次显示一个目标。
- 批量获取资料单次限制为 50 项，支持停止；结果缓存限制为轻量字段，不再保留整页 HTML。
- 普通网页和媒体请求会逐跳检查重定向地址，拒绝解析到内网/保留 IP 的目标，并限制最多 5 次重定向。
- 补充多目标输入下的单目标预览规则；本地/在线单项预览与打开网页等操作会明确使用第一个目标。

### 任务队列与并发

- 顶部目标框支持用 `/`、反斜杠或顿号一次输入多个下载目标；每个目标会创建独立任务。搜索词和 URL 路径中的斜杠会保留，E-Hentai 单个画廊 ID/Token 不会拆开。
- 并发限制从适配器固定值调整为按平台、按任务类别分别配置：设置页可设置平台总并发、作品/单项并发和作者/范围并发。作者、关注、搜索和范围类任务默认最多同时运行 1 个；总上限仍控制该平台所有任务。
- 多目标批次自动跟踪当前运行任务；Twitter 逐媒体记录完成、跳过及失败原因，并将已产出文件即时登记到任务详情。
- 任务日志新增级别筛选、关键词搜索，以及 TXT / JSON 导出；详情当前显示最近 500 条，导出会隐藏可识别的敏感字段。
- 日志默认自动跟随；拖动右侧滚动条时暂停，松开后回到底部继续跟随。

### 候选与历史批量操作

- 关注 / 用户候选和各平台历史支持多选后批量填入工作台；工作台保留准确目标列表，避免 URL 中的斜杠被误拆。
- 历史批量填入检查内容种类；混选不同内容种类时阻止操作，避免错误解释目标 ID。
- 关注 / 用户候选与相似搜索候选新增批量获取资料；相似搜索可批量填入普通网页目标。

## 2026-09-24

### 问题修复

- **保存路径切换卡死**：修复切换到非 C/D 盘（网络驱动器、移动硬盘等）时界面卡死的问题。原因是下载历史加载在 UI 主线程同步递归遍历目录，现已改为后台线程异步执行。
- **在线获取资料卡死**：修复点击「在线获取资料」和「本地预览」时界面卡死的问题。`load_profile_preview` 同样在主线程同步遍历输出目录，现已全部改为后台线程。
- **打包后在线获取失败**：修复打包版提示「推特脚本目录不存在」「缺少 config.json」的问题。PyInstaller 配置已包含 twitter / pixiv / jmcomic 爬虫脚本目录。
- **目录遍历异常保护**：`downloaded_users` 中的目录遍历增加 `try/except`，单个子目录或文件不可访问时自动跳过，不再导致整体加载失败。

### 新增功能

- **任务开始前确认弹窗**：点击「开始任务」后弹出确认窗口，展示当前下载设置，包括统一输出格式、公共压缩/解压、当前平台设置、保存目录和代理，并提示资源占用。点击「是」继续，「否」取消。
- **下载完成弹窗**：任务正常完成后弹窗显示任务 ID、下载文件数、总大小和保存目录；任务失败时弹窗提示查看日志。

### 问题修复（续）

- **设置页说明文档打不开**：设置页三个「使用说明」按钮（JMComic、浏览器登录、插件开发）原本尝试打开外部 `.md` 文件，打包后文档目录不存在导致报错。现已全部改为软件内置说明弹窗，不再依赖外部文件。
- **打包版在线获取资料失败**：`fetch_profile_preview` 使用 `sys.executable` 运行子进程脚本，但打包版中 `sys.executable` 指向 exe 文件而非 Python 解释器，导致脚本无法执行。现已改为在打包版中自动查找系统 `py` / `python` 命令运行脚本，并在未安装 Python 时给出明确提示。

### 功能优化

- **任务日志实时更新**：任务队列下方的任务详情日志在下载过程中实时刷新，无需手动点击任务查看最新进度。
- **智能滚动**：日志默认自动滚动到最底部；按住滚动条时暂停自动滚动，方便查看历史日志，松开后恢复。
- **浏览器驱动位置调整**：打包版中 ChromeDriver 存放在 exe 所在目录（`欲求达.exe` 同级），不再放在 `data/` 子目录，方便手动替换和管理。设置页「检测浏览器驱动」和「安装/更新驱动」按钮会自动使用新位置。

### 配置与打包

- **数据存储位置调整**：打包版（exe）的运行数据（数据库、Cookie、浏览器配置、ChromeDriver 等）从 `%LOCALAPPDATA%/YuqiuDa/` 改为 **exe 所在目录的 `data/` 文件夹**，实现绿色便携。源码运行版仍使用项目目录下的 `data/`。
- **ChromeDriver 位置**：统一保存在 `data/software_app/browser/chromedriver.exe`，设置页可自动检测和安装。
- **打包配置**：新增 `欲求达.spec`，包含爬虫脚本数据打包，生成 GUI 版（欲求达.exe）和 CLI 版（欲求达-cli.exe）。

### 压缩功能说明

- 默认压缩模式为「不压缩」，需在设置页手动开启。
- 「按资源文件夹压缩」：每个子文件夹生成一个 ZIP，保存在该文件夹内，命名为 `{文件夹名}_归档_{任务ID}.zip`。
- 「按整个任务压缩」：在任务输出根目录生成一个 ZIP。
- 开启「压缩校验成功后清理源文件」后，仅在 ZIP 写入并校验通过后删除源文件。
