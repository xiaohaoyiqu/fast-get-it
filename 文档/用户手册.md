# 欲求达操作与使用说明

本文说明如何启动和使用“欲求达”工作台，包括 Twitter/X、Pixiv、JMComic、Bluesky、Instagram、E-Hentai/ExHentai、相似图片搜索、跨平台黑名单、任务队列和下载库。

## 1. 启动软件

从源码运行时，首次使用先在项目目录安装依赖：

```powershell
python -m pip install -r requirements-app.txt
```

启动桌面工作台：

```powershell
python .\run_software.py
```

主界面左侧用于查找目标、查看资料和管理黑名单；右侧用于创建任务、查看平台候选、相似搜索、任务队列、下载库和设置。

## 2. 首次配置

打开右侧 **设置** 页面，至少检查以下项目：

1. **默认保存目录**：新任务默认保存到这里。
2. **代理 URL**：可留空，也可填写 `http://127.0.0.1:端口`、HTTPS 或 SOCKS 代理。不要填写带账号密码的代理地址。
3. **失败自动重试**：适合临时断网或单个媒体请求失败。
4. **统一输出格式**：分别选择图片、视频、动图和音频格式。
5. **公共压缩 / 解压**：默认关闭；需要时可按整个任务或资源文件夹生成 ZIP。
6. **Chrome / ChromeDriver**：Twitter、Google Lens 和部分网页登录需要浏览器自动化。先点检测；驱动缺失、损坏或主版本不匹配时点 **安装 / 更新驱动**，软件会按 Chrome 版本自动选择，不需要用户手动找版本。

修改完成后点 **保存设置**。设置只影响之后创建或重试的任务。

### 通过浏览器获取登录 Cookie

设置页的 **浏览器登录与 Cookie** 支持 Twitter/X、Pixiv、FANBOX、Instagram、E-Hentai 表站和 ExHentai 里站。普通平台可点击 **打开登录浏览器并获取**；EH 为降低自动化登录拦截，使用普通 Chrome。表站流程为 **打开登录 → 关闭全部专用窗口 → 获取**；里站流程为 **打开登录 → 登录后进入里站 → 确认正常显示并关闭全部窗口 → 获取**。若内置流程仍受阻，各平台可点 **请求头 TXT → JSON**，选择从浏览器 DevTools 复制的完整请求/响应头文本；软件检查必要 Cookie、生成不覆盖旧文件的 Cookie JSON，并询问是否导入。EH 会在线验证后才保存，JMComic 会另外保留原 TXT 中允许的安全请求头。窗口使用当前代理设置，软件不保存账号密码；TXT 和 JSON 都是明文凭证，切勿分享。

Pixiv 与 FANBOX 需要分别获取，保存时会合并到同一个文件。JMComic 在自己的设置卡片中使用 **打开普通 Chrome 登录 → 关闭登录窗口 → 登录完成后获取**，避免验证阶段出现自动化参数。Bluesky 公开接口不需要 Cookie，账号黑名单仍使用临时应用密码。详细步骤见 [浏览器登录与 Cookie](平台/浏览器登录与Cookie.md)。

## 3. 通用下载流程

### 单个目标

1. 在顶部选择平台。
2. 选择该平台的搜索种类或目标类型。
3. 在 **目标 / URL** 输入用户名、作品 ID、章节 ID、关键词或链接。
4. 点 **本地预览** 检查目标识别结果；此操作优先使用本地资料。
5. 需要最新信息时点 **在线获取资料**。
6. 确认保存目录和下载类型后点 **开始任务**。
7. 到 **任务队列** 查看进度、日志和已下载文件。

### 多个候选

1. 在平台候选页执行搜索、读取关注、读取收藏或导入名单。
2. 使用 Ctrl、Shift 或 **全选当前页** 选择多个候选。
3. 点 **加入队列**。
4. 多出的任务会排队，并按平台并发上限自动开始。

候选列表中的 **填入目标** 只把单项带回顶部输入框；**获取资料** 用于查看选中项；**加入队列** 才会创建下载任务。

## 4. Twitter/X

### 下载用户内容

1. 选择 **Twitter/X**。
2. 输入 `@用户名` 或主页地址。
3. 在 **下载类型** 中填写需要的类型：

   - `1`：图片
   - `2`：视频
   - `3`：GIF
   - `4`：音频

4. 多种类型用英文逗号分隔，例如 `1,2,3`。
5. 在线获取资料可读取名称、头像、简介、主页和可识别的 Skeb、FANBOX 等外链。
6. 点 **开始任务**，会弹出确认窗口显示当前下载设置（统一输出格式、公共压缩/解压、当前平台设置、保存目录等），确认后开始下载。

### 下载单条帖子

把 `x.com/用户名/status/帖子ID` 或 `twitter.com/用户名/status/帖子ID` 填入目标框。单帖任务只处理目标帖子本身的媒体，会排除同页推荐、回复中的其他帖子媒体。

### 使用关注列表

1. 打开 **推特关注/候选**。
2. **读取本地关注** 不访问网站，直接加载缓存。
3. **更新新的** 从顶部扫描，发现与旧缓存重叠后停止，适合日常增量更新。
4. **更新全部** 读取完整关注列表，可核对新增和已取关账号。
5. 更新过程中可以停止；已经取得的分页会保留为部分缓存。
6. 选择账号后可批量加入队列，Twitter 同时最多运行 5 个目标。

### 导入和导出关注

- 导入支持 JSON、CSV、TXT 和 LIST。
- TXT 可每行写一个 `@用户名`。
- 导入只合并，不会凭离线文件删除已有关注。
- 导出支持 JSON 和 CSV。

## 5. Pixiv

### 登录 Cookie

Pixiv 公开内容可能不要求登录。作品收藏、小说收藏、私密关注、R-18、Premium 历史和 FANBOX 登录内容需要对应 Cookie。推荐直接使用设置页的 **浏览器登录与 Cookie**；以下导出文件方式继续保留。

1. 在浏览器登录 Pixiv。
2. 导出当前域名 Cookie 为 JSON。
3. 在 Pixiv 候选页点 **导入 Cookie**。
4. 回到设置页点 **检查 Pixiv 连接/头像**。

Cookie 至少应包含 Pixiv 使用的 `PHPSESSID`；FANBOX 登录内容通常还需要 `FANBOXSESSID`。

### 查找和下载

Pixiv 可选择以下目标或搜索种类：

- 作品 ID、作者 ID、漫画系列。
- 小说 ID、作者小说、小说系列。
- 标签、标题 / 简介、作者 + 标签。
- 排行榜、新作。
- 作品收藏、小说收藏和浏览历史。
- FANBOX、Sketch。

设置页可以配置日期、最低收藏数、公开/私密范围、年龄分区、单任务作品上限和 AI 作品过滤。选择具体 Pixiv URL 时，软件会按 URL 的实际类型创建任务。

### 关注和收藏缓存

- **更新新的 / 更新全部** 用于关注画师。
- **更新我的作品收藏 / 小说收藏** 会分页保存完整本地缓存。
- 候选页可再按作品 ID、作者、标签、标题和日期筛选本地收藏。
- 本地筛选不会改写网站收藏，也不会删除完整缓存。

## 6. JMComic

本节用于日常操作；Cookie 类型、页面去向和账号功能边界可继续查看 [JMComic 使用与登录](平台/JMComic使用与登录.md)。

### 登录与 Cloudflare 配置

JMComic 的普通页面和登录页面都可能要求 Cloudflare 验证。只导入 `cf_clearance` 不能代表账号已登录；收藏、追更、观看记录和站内屏蔽标签还需要 `AVS`。

推荐配置方法：

1. 让浏览器使用与软件相同的代理，打开当前 JMComic 域名并完成验证和登录。
2. 按 F12 打开开发者工具，进入 **Network（网络）**。
3. 选择一个当前 JMComic 域名下成功返回的请求。
4. 复制完整请求标头到 TXT。可直接点 **请求头 TXT → JSON** 自动转换并导入；软件也支持 Cookie JSON 和 Netscape `cookies.txt`。
5. 在浏览器控制台执行：

   ```javascript
   navigator.userAgent
   ```

6. 把返回的一整行内容填入 **设置 → JMComic · 可用 → 浏览器 User-Agent**。
7. 在 **站点与登录资料** 中填写当前域名、账号用户名、漫画收藏目录 ID 和小说收藏目录 ID。
8. 点 **导入登录资料**，选择刚才的 JSON 或 TXT；候选页也提供同一入口。
9. 查看登录资料状态，再点 **检查连接**。登录资料状态分别说明 AVS、Cloudflare 请求头和账号用户名；连接状态只说明当前站点能否返回网页。

如果返回 HTTP 403，应在相同域名、代理出口和浏览器环境下重新完成验证，并一起更新 Cookie、请求标头和 User-Agent。

### 搜索种类

- **综合搜索、作品搜索、作者搜索、标签搜索、角色搜索**：输入关键词。
- **分类 / 排行**：使用设置中的分类、排序和时间范围。
- **漫画收藏夹**：读取个人主页中的漫画收藏目录；按钮会显示为 **读取漫画收藏**。
- **小说收藏夹**：只读显示小说候选；当前不下载小说正文。
- **追更连载**：读取账号追更漫画；按钮会显示为 **读取追更连载**。
- **漫画观看记录、小说观看记录**：只读获取网站记录，不会清除站内历史；候选页签和读取按钮会随当前种类改名。

一次搜索最多保留 15 个候选。可以选择候选后点 **编辑 JM 标签**，为下载目录附加最多 5 个标签；也可以移除不需要的候选。

### 漫画预览和下载

- 漫画 ID 或 `/album/{id}`：本地预览显示将进入漫画详情和章节目录页；在线资料可读取标题、作者文字、标签、章节、封面和第一页。
- 章节 ID 或 `/photo/{id}`：进入章节正文阅读页，在线资料可读取图片列表和分割图参数。
- **打开网页** 使用系统浏览器打开对应详情页或正文页。
- 下载时会按章节建立目录、按页码保存图片，并自动还原站点分割图。
- 设置中可选择额外保存封面，以及按每 30 张生成 PDF、长图或两者。
- JMComic 同时最多运行 3 个任务。

## 7. Bluesky 与 Instagram

### Bluesky

Bluesky 可读取公开用户、公开关注、用户搜索、帖子搜索、作者媒体和具体帖子，不需要登录。输入 handle、自定义域名 handle、DID、主页或帖子链接；下载类型 `1` 为图片，`2` 为视频。帖子全文搜索可能被部分代理出口拒绝，此时用户、公开关注、作者动态和具体帖子仍可使用。

### Instagram

Instagram 当前标记为可用，支持精确用户名、主页、帖子和 Reels 链接。静态页面不返回资料时会自动切换到登录浏览器渲染。公开页面被改成登录页时，优先在设置页通过可见登录浏览器获取；也可导入 JSON、Netscape `cookies.txt` 或 Cookie 请求头。普通账号关注列表尚未接入。

Bluesky 的“用户搜索”和“关注账号”候选提供 **关注 Bluesky 账号**、**取消关注**。只允许单选用户候选，每次操作先明确确认，再临时询问自己的 handle 和应用密码；handle 可保存以便下次填写，应用密码和访问令牌不会保存。重复关注或取消未关注账号不会重复写入。

完整说明和油猴脚本对应关系见 [Bluesky 与 Instagram](平台/Bluesky与Instagram.md)。

## 8. E-Hentai / ExHentai

选择 **E-Hentai / ExHentai** 后，可输入完整画廊链接或按表站/里站关键词搜索。表站公开候选通常可匿名读取；里站和收藏夹需要登录 Cookie。表站与里站账号允许不同，必须在设置页分别使用各自的普通 Chrome 资料登录或导入，软件不会复用账号。里站登录前会提示尽可能使用非亚洲代理/VPN，并要求登录与访问保持同一出口。普通 Chrome 也会准备官方 `uconfig.php` 设置页；当前先在官网页修改，软件不会猜测提交可能涉及配额或消费的选项。在线资料显示画廊 ID、标题、上传者、发布时间、页数、大小、标签、评分、缩略图、种子数量和官方归档可用性。

候选页单选具体画廊后可点 **加入 EH 收藏** 或 **移出 EH 收藏**。加入时会在线读取该账号当前的 10 个自定义分类名称、现有分类和注释，再让用户选择或修改；每次写入都会先确认，并在提交后复读站内状态。按钮会按画廊所属表站/里站使用对应账号，不会借用另一个站点的 Cookie。

下载任务默认保存一份 JSON 元数据和阅读页正常展示的图片，不请求 `Download original`。设置页可手动开启保存最新一个 `.torrent`，该开关默认关闭；种子通过完整结构与安全路径校验后才入库。第二个独立开关可使用 aria2 下载种子内容，仍默认关闭；可检测现有 aria2，或在 64 位 Windows 安装经固定 SHA-256 校验的官方便携版。首次保存启用状态会提示 P2P 的公网 IP 与上传风险，完成后停止做种。软件不会自动请求可能扣除 GP/Credits 的官方 ZIP。AI 生成/辅助标签默认过滤。完整登录和目录说明见 [E-Hentai / ExHentai](平台/E-Hentai使用与登录.md)。

## 9. 相似图片搜索

1. 打开 **相似搜索** 页签。
2. 选择单张图片，或选择文件夹递归读取最多 20 张图片。
3. 设置每张图片的候选数和人工验证等待时间。
4. 点开始搜索；Google Lens 浏览器会打开。
5. 出现人机验证时，在浏览器中手动完成，软件会继续等待结果。
6. 搜索完成后，在右侧候选表选择需要的来源页面。

可对候选执行：

- 在浏览器打开页面。
- 检查链接状态和最终跳转地址。
- 导出 CSV、JSON 或纯 URL TXT。
- 将 Pixiv 作品交给 Pixiv 下载器。
- 将 X 单帖交给 X 下载器。
- 将普通页面交给网页资源爬虫。
- 屏蔽或解除屏蔽具体作品、帖子或页面。

Google Lens 的“AI 概览”不是已经确认的相似图片结果。出现 **视觉搜索内容已过期 / 图片未找到** 时，需要重新上传原图；软件会保留提示，不会把它当成正常的零结果。

## 10. 跨平台黑名单

### 主动屏蔽

- 在左侧资料卡点 **屏蔽作者**，屏蔽当前作者。
- 点 **屏蔽作品/页面**，只屏蔽当前作品、帖子或页面。
- 在平台候选或相似搜索候选中可批量屏蔽作者或作品。
- JMComic 还支持按作者文字和站内标签过滤漫画。

作者规则和作品规则互相独立。屏蔽一件作品不会自动屏蔽作者的其他内容。

### 管理规则

点 **管理黑名单** 后可以：

- 按平台、名称、账号或作品查找。
- 新增、查看、修改和删除规则。
- 导入或导出指定平台 JSON/TXT 名单。
- 查看作者规则、作品规则和待绑定的 X 数字账号 ID。

### 取回平台原有记录

- **X 数据归档**：选择完整归档 ZIP，或单独的 `block.js`、`mute.js`。
- **Pixiv 在线静音**：使用现有 Pixiv Cookie 只读获取；也可导入浏览器保存的设置页 HTML。
- **Bluesky 账号**：临时输入账号和应用密码，读取官方屏蔽及可选静音列表；应用密码不会保存。
- **JMComic 站内屏蔽标签**：使用 JMComic 登录会话读取 `tag_block` 页面。

取回结果会先显示来源、数量和示例，确认后才合并到本地黑名单。它不会修改任何平台账号上的拉黑或静音状态。

## 11. 任务队列

任务队列上方显示所有任务，下方显示当前选择任务的详情、参数、错误、日志和文件。

- **批量重试**：用于失败、取消或支持修复重试的旧任务。
- **批量取消**：停止排队或运行中的任务。
- **删除任务记录**：删除数据库中的任务、日志和文件索引，不删除本地媒体。
- **填入工作台**：把旧任务目标和类型恢复到顶部输入区。
- **打开输出目录**：打开任务保存位置。
- 任务正常完成后会弹出提示窗口，显示下载文件数、总大小和保存目录；失败时也会提示查看日志。

退出软件时如果仍有任务，会先询问是否停止。已经下载完成的文件会保留。

## 12. 下载库

下载库包含三部分：

1. 平台、作者和文件夹列表。
2. 所选文件夹的文件列表。
3. 当前图片或文件预览。

可用操作：

- 多关键词搜索平台、路径、文件名、类型、标题、作者、章节和标签。
- 刷新数据库索引或扫描保存目录中新出现的文件。
- 打开文件、打开文件夹、复制绝对路径。
- 重命名单个文件。
- 把明确选中的文件移到 Windows 回收站。
- 小窗口下点 **显示预览** 展开图片预览区。

清理平台历史与删除本地文件是两项操作。清理历史默认保留本地媒体；删除媒体必须在下载库明确选择并确认。

## 13. 压缩、PDF 和长图

在设置页的 **公共压缩 / 解压** 中选择：

- **按整个任务压缩**：一个任务生成一个 ZIP。
- **按资源文件夹压缩**：每个漫画章节或资源目录分别生成 ZIP。
- **安全解压下载到的 ZIP**：只解压通过路径和容量检查的普通 ZIP。
- **压缩校验成功后清理源文件**：只有 ZIP 写入并重新校验成功后才删除该任务明确报告的源文件。
- 生成的 ZIP 文件保存在对应资源文件夹内（按资源文件夹压缩时）或任务输出根目录内（按整个任务压缩时），文件名为 `{文件夹名}_归档_{任务ID}.zip`。

JMComic 的章节后处理可以单独选择 PDF、长图或两者，每组最多处理 30 张图片。

## 14. 常见问题

### 页面返回 403

- 检查当前站点域名是否与 Cookie 一致。
- 检查软件代理是否与浏览器取得 Cookie 时一致。
- JMComic 需要一起更新请求标头、User-Agent 和 `cf_clearance`。

### 提示缺少登录会话

- Pixiv 检查 `PHPSESSID`，FANBOX 检查 `FANBOXSESSID`。
- JMComic 账号功能检查 `AVS`；只有 `cf_clearance` 不能读取收藏和历史。
- Instagram 登录限定页面检查 `sessionid`；Cookie 必须来自当前域名及相同代理环境。

### 启动显示 No module named 'Crypto'

执行 `py -3.12 -m pip install "pycryptodome>=3.20"`，然后也用 `py -3.12 .\run_software.py` 启动。若使用其他 Python 版本，把两条命令中的版本保持一致。

### Google 显示视觉效果已过期

重新选择原图并开始新搜索。不要继续切换已经失效的匿名 Lens 结果页。

### 缩小窗口后内容看不到

任务日志、左侧资料、相似搜索左栏、下载库文件表和关注操作区都有滚动条或折叠入口。把鼠标放在对应区域使用滚轮；下载库图片预览可先收起，为文件表保留空间。

### 清理历史后文件还在

这是正常行为。历史清理只删除数据库记录；需要删除媒体时，到下载库选择具体文件并移到回收站。

## 15. 本地数据和隐私

- 打包版（exe）：Cookie、浏览器请求头、数据库、关注缓存和下载记录保存在 exe 所在目录的 `data/software_app/` 中。
- 源码运行版：保存在项目目录的 `data/software_app/` 中。
- ChromeDriver 驱动：打包版保存在 exe 所在目录（与 `欲求达.exe` 同级），源码版保存在 `data/software_app/browser/chromedriver.exe`。首次使用可在设置页点击「检测浏览器驱动」和「安装/更新驱动」。
- 软件不会保存 JMComic 密码或 Bluesky 应用密码。
- Cookie、请求头、token 和密码不会显示在任务详情或运行日志中。
- 不要把 Cookie、完整请求标头、数据库或个人账号缓存提交到 Git 或发送给其他人。
- 网站上的收藏、观看记录、屏蔽和静音读取均为只读；只有本地黑名单会发生变化。
