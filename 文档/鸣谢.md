# 鸣谢

欲求达是在多个开源项目、公开文档和长期维护经验的基础上完成的。感谢下面这些项目的作者和贡献者公开源码，让登录流程、媒体解析、下载恢复与平台差异有了可核对的参考。

## 参考项目

### twitter_Crawler

[muzi-xiaoren/twitter_Crawler](https://github.com/muzi-xiaoren/twitter_Crawler) 提供了早期 Twitter/X 爬虫的 Selenium 页面操作、Cookie 登录、网络响应读取和媒体下载思路，采用 Apache-2.0 许可证。欲求达当前的 Twitter/X 模块在此基础上重新整理了平台适配、任务管理、图片与视频入口、单帖解析、关注数据、文件命名、失败重试和下载记录。

### JMComic-Crawler-Python

[hect0x7/JMComic-Crawler-Python](https://github.com/hect0x7/JMComic-Crawler-Python) 提供了完整的 JMComic Python API、网页端与移动端接口、图片解码、搜索和收藏等实现参考，采用 MIT 许可证。欲求达在桌面端接入 JMComic 时，参考了它对接口、配置和图片处理流程的长期实践。

### PixivUtil2

[Nandaka/PixivUtil2](https://github.com/Nandaka/PixivUtil2) 是维护时间很长的 Pixiv 下载工具，覆盖作品、画师、收藏、排行、小说、动图、FANBOX 与 Sketch 等场景，采用 BSD-2-Clause 许可证。欲求达的 Pixiv 功能规划和边界判断从这些成熟功能中获得了重要参考。

三份参考源码的本地整理版存放在 [xiaohaoyiqu/greater-trawler](https://github.com/xiaohaoyiqu/greater-trawler)。该仓库保留各项目原有许可证和来源说明，不替代上游仓库；获取最新版、提交问题或阅读原始文档时，应以前述上游项目为准。

谷歌图片搜索工具来自本项目作者自己的早期实现，因此不列为第三方来源。

项目也受益于 Python 生态和外部工具，包括 Selenium、Requests、Pillow、MoviePy、PyCryptodome、curl_cffi、TkinterWeb 与 aria2。感谢这些项目的维护者持续处理浏览器兼容、网络请求、图像与媒体处理、HTML 展示和下载任务中的大量基础问题。

同时感谢参与实际登录、页面兼容、下载和打包验证的使用者。平台页面会持续变化，许多修复都来自可复现的页面样本、错误信息和清楚说明账号条件的反馈。
