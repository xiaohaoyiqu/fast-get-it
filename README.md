# 欲求达

欲求达是一个 Windows 桌面下载工具，用来查找、预览和保存多个内容平台上的图片、视频、音频及作品元数据。桌面端提供候选、任务队列、下载历史、预览和黑名单；账号密码留在网站登录页。

项目源码：[xiaohaoyiqu/fast-get-it](https://github.com/xiaohaoyiqu/fast-get-it)。配套浏览器脚本：[xiaohaoyiqu/tempermonkey-scripts](https://github.com/xiaohaoyiqu/tempermonkey-scripts)。

源码与文档同步至 **2026-10-31**，本次同步不包含 EXE 发行包。最新完整回归 **998 项通过（167.429 秒）**，16 组本机流程共 131 项通过；本地独立 GUI／CLI 验收包启闭五项通过。实站小样本通过不等于所有平台业务都通过，JM／Google／Instagram 等边界见 测试报告（本地记录，不随仓库上传）。

当前源码的独立验收包位于本地 `data/software_app/verification/daily-acceptance-20261031/package/dist/`，包含新清单和集合补下功能；**根 dist 未替换**。验收包不随 Git 上传，也不会自动带上原 dist 的账号配置。实站已通过 Twitter、Bluesky、Pixiv 匿名作品、EH 表站及普通网页的小样本图片下载；JM 当前 403、Google 需人机验证，Instagram 仅验证主页小图，里站缺独立 Cookie。

下载库的 **筛选 / 导出 / 清理** 窗口新增 **导出成品清单** 和 **读取清单核验**：按所选文件根目录记录相对路径、大小、SHA-256 及必要来源信息，核验后报告匹配、缺失、变化、占用或无有效基线。支持文件夹迁移后核验及后台停止，不改写媒体、索引和任务历史。清单只证明相对本地基线的变化，不证明来源可信。操作限制见用户手册；此能力已包含在独立验收包中。

本轮公共媒体和网页格式转换接入可取消 FFmpeg 入口，取消／失败不发布临时成品；有效 Retry-After 保留完整期限，不再截到五分钟。超出系统等待范围的期限明确失败。新增能力已包含在独立验收包中，根 dist 仍为此前 HTTP 检查点版。

当前源码为 Pixiv 漫画系列、作品搜索和排行榜增加固定作品范围及逐媒体补下：失败页补下沿用原目录，站内列表、作者名或标题变化不扩大补下范围；按当前设置完整重试才重新发现。作品搜索额外核对年龄范围和最低收藏数，旧收藏计划保持兼容。此能力已包含在独立验收包中，根 `dist` EXE 仍为此前 HTTP 检查点版；也可用下方源码启动命令体验。

本轮 HTTP 续传增加本地摘要检查点：恢复前验证前缀，舍弃未提交尾部，内容损坏或旧记录缺少摘要时重新下载；8 MiB 样本的真实强退恢复已验收。此前的最终资源地址绑定、Windows 浏览器独立进程组、安装失败保护、Pixiv 分页完整性、作品收藏补下、HLS 恢复、缓存预览清理及 aria2 每进程限速保留。

本机已有打包文件时，可使用 `dist/欲求达.exe` 启动；从 Git 克隆后请按下文从源码启动或自行打包。设置及数据见 [用户手册](文档/用户手册.md)。当前能力不等于所有平台账号均已实站验收；待办和工作区约束统一维护在 [开发接续](文档/开发暂停与接续.md)，变更历史见 [更新日志](文档/更新日志.md)。

## 从源码启动

建议使用 64 位 Python 3.10 或更高版本。

```powershell
git clone https://github.com/xiaohaoyiqu/fast-get-it.git
cd fast-get-it
python -m pip install -r .\requirements-app.txt
python .\run_software.py
```

首次启动后打开“设置”，先确认下载目录、代理和 ChromeDriver。点击“安装 / 更新驱动”时，软件会读取 Chrome 版本并自动选择对应驱动，不需要手动下载版本号。

Driver 检测结果显示在设置页按钮下方，包含 Chrome／Driver 版本和实际路径。工作台顶部新增 **执行前检查** 和 **人物配置**：前者只检查本机目录、磁盘空间与工具；后者为 Twitter、Pixiv、Bluesky、Instagram 的明确作者／账号精确绑定下载类型、格式及可选目录。每个任务保存独立设置快照，切换人物或修改设置不影响旧任务；默认 **按原设置重试**，只有明确选择 **按当前设置重试** 才更新配置。支持范围和匹配限制见 [用户手册](文档/用户手册.md)。

通过“浏览”选择的保存目录会立即记住，手动输入的有效目录会在离开输入框、开始任务或正常退出时记住；重启优先使用上次目录。其他设置仍需点击“保存设置”。Twitter 的下载浏览器、在线资料、关注刷新和头像请求均使用传入的已保存代理配置。

任务支持多目标输入、候选批量加入队列和按平台/任务类别配置并发；队列会分别显示每项任务的当前操作，并提供日志筛选、导出、清理和批量重试。Twitter 图片、视频还可选择日期命名、保留原始文件名副本，以及导出未完成媒体清单，具体范围见 [用户手册](文档/用户手册.md)。

顶部 **混合平台批量任务** 可一次粘贴最多 100 行完整链接，离线识别平台和范围，标出重复、无效及普通网页回退项，再将选中项分别入队。每批创建独立目录，各条目使用独立子目录和原平台并发限制；根目录的 `批次汇总.txt` 随状态更新。停止后续入队保留已创建任务；失败重试创建独立任务，重启不会自动执行未入队条目。

公共 HTTP 下载器和 Twitter 视频/GIF 已支持有条件断点续传：新续传资料保存在成品同级、带归属标记的 `.yuqiuda-http-<摘要>/` 目录中，重试时核对原始 URL、ETag 或 Last-Modified 及总长度；资源变化或服务端不支持 Range 时重新下载。旧版成品旁的 `.part/.resume` 保留，因无法可靠区分真实附件，不自动接管或清理；升级前应关闭旧实例。主要媒体下载与转换链路使用线程及进程间输出锁。设置中的“媒体文件重名时”可选择复用、覆盖、报错或自动改名保留两者，创建任务时保存策略；FANBOX/Sketch 媒体也已接入。自动改名采用 `文件 (2).扩展名` 等名称，下载库记录实际保存路径；覆盖范围及例外见用户手册。

队列支持批量暂停和恢复，在下载分块、循环或进度回调的安全检查点生效；运行任务暂停后保留并发槽位和输出锁。正常退出或意外退出后的未完成任务，可在下次启动后点“恢复中断任务”，确认后沿用原任务 ID、参数、目录和批次关系，原暂停任务仍保持暂停；主动取消的任务不在此列。恢复会重新读取目标，复用已有成品及可验证续传文件；Bluesky 支持对符合条件的 HLS 完整分片进行校验后复用，不恢复浏览器现场，不会在启动时自动执行网络任务。

任务层按结构化异常区分站点限流、访问拒绝、资源不存在、网络超时、TLS、文件重名和磁盘错误，永久错误不再自动重跑整个任务。公共 HTTP、Twitter 请求、公共 JSON、网页直连、JM、Bluesky API／HLS、Instagram 静态页面及 FANBOX/Sketch JSON 请求对 429/503 共用本实例的主机退避期限，等待可在任务检查点暂停或取消；管理器工作线程会显示等待原因及大致剩余时间。浏览器直接请求、其他外部引擎、BT 及其他实例不在共享范围内，具体规则见用户手册。

下载库的“筛选 / 导出 / 清理”可按平台、资源类型、作者、标题、精确标签及入库/发布日期筛选完整索引，导出 CSV，或预览确认后仅清索引、移到回收站并清索引。导出不受文件表显示上限限制；清理单次最多 10000 条，执行时会跳过预览后变化的索引和不适合回收的文件，并与同一数据库中的下载任务互斥。

JM 的 PDF/长图与公共 ZIP 创建也使用任务的重名策略，按实际保存路径入库。合成文件先生成临时成品再替换；归档清理源文件前核对文件身份与内容摘要，复用旧 ZIP 时还需确认成员内容匹配。变化或无法清理的源文件保留，下载库只移除实际删除文件的索引，原因写入任务日志。

设置中的“启用媒体 HTTP 总限速”让本实例的 HTTP 媒体任务共用一个速率预算，单位为 KiB/s（1024 字节/秒），默认关闭。保存后立即作用于已有任务，关闭时保留速率值；暂停或取消可中断限速等待。Bluesky HLS 分片及初始化数据也参与预算；它是应用层媒体字节节流，短时读取受缓冲影响。浏览器直接接收、其他外部引擎、BT、资料/头像请求及其他实例不共享此预算。

同版本实例共享数据库时，任务会记录实例归属，并用操作系统锁判断所属实例是否仍在执行任务；启动时保留存活实例的状态，只将已退出实例的遗留任务转为取消。活跃实例的任务记录也受删除保护。下载库原有“重命名”“移到回收站”入口现已接入维护门禁、文件锁及索引/文件状态复核。升级前先关闭不记录任务归属的旧版实例；当前仍不支持从另一实例远程暂停或取消任务。

常用诊断命令如下。

| 命令 | 用途 |
| --- | --- |
| `python .\run_software.py modules` | 列出平台模块及缺少的配置 |
| `python .\run_software.py browser-driver` | 检查 Chrome 与 ChromeDriver 版本 |
| `python .\run_software.py browser-driver --download` | 自动安装或更新匹配的 ChromeDriver |
| `python .\run_software.py aria2` | 检查可选的 aria2 BT 引擎 |

## 打包为 exe

使用 PyInstaller 打包，配置文件为项目根目录的 `欲求达.spec`：

打包前须准备 `1.ico` 和 `software_app/crawlers/twitter/chromedriver.exe`。驱动二进制由 `.gitignore` 排除，克隆仓库后不会自带；设置页自动安装的驱动通常位于运行数据目录，需将匹配的驱动复制到上述打包路径。

```powershell
python -m pip install -r .\requirements-app.txt
python -m PyInstaller .\欲求达.spec --clean --noconfirm
```

打包产物在 `dist/`，包含独立运行的 `欲求达.exe`（GUI 版）和 `欲求达-cli.exe`（命令行版）。两个程序均为单文件包，不依赖 exe 旁边的 `_internal` 目录；可以将 exe 移到其他有写入权限的文件夹运行。`--noconfirm` 会替换打包输出；请先关闭正在运行的软件，并将需要保留的旧版文件移出 `dist/`。

运行时会将程序文件解压到系统临时目录，用户数据继续保存在 exe 所在目录的 `data/`，下载目录仍可在设置中修改。更新时只需关闭程序并替换 exe，保留原来的 `data/` 和下载目录。打包器会强制 Requests 使用 Python 标准库 JSON，避免旧版残留的半安装 `simplejson` 目录导致启动时报 `cannot import name 'JSONDecodeError'`。

## 登录资料和本地数据

源码运行时数据保存在项目目录的 `data/software_app/`；打包版（exe）运行时数据保存在 exe 所在目录的 `data/software_app/`，可绿色便携使用。下载目录可以在设置中修改。

默认下载位置：源码版为 `data/downloads/`，exe 版为当前用户的 `Downloads/欲求达/`。可用环境变量 `YUQIUDA_HOME` 指定运行根目录（数据保存在其下的 `data/software_app/`），用 `YUQIUDA_OUTPUT_DIR` 指定首次未配置时的默认下载目录；已保存的界面下载目录优先。

Twitter/X、Pixiv、FANBOX 和 Instagram 可以在设置页打开临时登录浏览器。JMComic 使用普通 Chrome 登录资料，关闭登录窗口后再读取 Cookie。EH 仅手动填写或导入 Cookie，保存不联网，验证单独执行；表站与里站分别保存会话，两个账号不会互相覆盖。

Cookie、请求头、SQLite、浏览器资料和下载记录不会进入源码仓库，也不应复制到问题反馈或聊天记录中。

## E-Hentai 种子下载

保存 `.torrent` 与使用 aria2 下载内容是两个独立开关，默认都关闭。aria2 安装时会校验 SHA-256，任务完成后停止做种；当前命令同时关闭 DHT、IPv6 DHT、PEX 和局域网节点发现。

BT 下载期间，Tracker 和其他节点仍可能看到公网 IP，也可能产生上传流量。请确认网络环境和内容使用权限后再开启。软件不会自动购买可能消耗 GP 或 Credits 的官方归档。

## 开发检查

开发依赖为 `requirements-dev.txt`，检查配置为 `ruff.toml`：

```powershell
python -m pip install -r .\requirements-dev.txt
python -m unittest discover -s tests -v
python .\scripts\check_quality.py
python .\scripts\check_documentation.py
```

当前项目虚拟环境可直接运行 `.\.venv\Scripts\python.exe scripts/check_quality.py`。检查脚本默认不修改文件；加 `--format` 只整理脚本列出的新增文件，不会全仓格式化或运行测试。

基础错误检查、统一排版检查和真实站点验收分别记录，完整命令及当前排版差异见 [开发与架构说明](文档/开发与架构说明.md#开发检查)。
